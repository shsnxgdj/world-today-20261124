A one-page newspaper front page summing up 24 November 2026 world news in a single AI-generated image. The image is built from six Reuters-verified stories from that day, with the main illustration clearly labelled AI-GENERATED ILLUSTRATION.

## Run it

```sh
node main.ts
```

This copies `entry.png` (1024×1024) to `/output/entry.png`. Deterministic: same bytes in, same bytes out. Outside the grader's container, set `MAKEFUN_OUTPUT_DIR` to choose the output folder, for example `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
